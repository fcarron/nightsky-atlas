# Standard DSO Candidate Review

Review of the 81 user-supplied DeepskyLog targets (observations with apertures up to 210 mm). Matching used the current normalized NightSkyAtlas catalogue, canonical IDs, cross-identifiers, catalogue records and aliases. Baseline selection totals were captured before this curation from the same production configuration.

The curated list activates 76 targets in Standard. Standard selection is inherited by Deep under the existing edition hierarchy; Pocket policy is untouched. No catalogue facts, symbol geometry, visibility scoring, or object dimensions were changed. UCC `r_50` remains a member-radius statistic and is never used here as a visual diameter.

Five candidates are not included: IC 5067 (identity ambiguity), NGC 6874 (UCC `bad_oc=y`), NGC 206 (no meaningful standalone cluster extent within M31), NGC 1435 (hard star-label overlap on S041/S056), and NGC 4425 (hard conflict on S051). The lower UCC confidence values for NGC 6773, NGC 2394 and NGC 6837 were recorded but did not override their non-flagged catalogue identities and supplied observing history.

## Deliberate handling of special cases

- **IC 5067 / IC 5070:** the alias collision is unresolved in the normalized catalogue, so the candidate is not added as another object. The already-selected IC 5070 record remains the only enabled Pelican-region representation from this match.
- **NGC 604 / NGC 346:** selected using their existing catalogued identities inside M33 and the SMC. No parent-galaxy/cluster extents are rewritten.
- **NGC 1435:** deferred because its distinct 30′ Pleiades reflection-nebula outline overlaps existing star labels on S041/S056. **NGC 4425:** a counterfactual S051 build without this target resolved the Virgo hard issue; the rest of the candidate set stays selected. **NGC 6979** remains as a separate catalogued Veil SNR patch, not a second outline for the full complex.
- **Stephan’s Quintet:** NGC 7320, 7318A, 7317 and 7319 remain four individual galaxy objects. Existing HCG 92 group selection is unchanged.
- **IC 348:** the canonical record is an existing bright-nebula object, not an independent open-cluster record in this store. It is selected once with that existing type; no duplicate cluster is synthesized.
- **UCC sizes:** where a cluster has no independently sourced visual extent, the existing generic symbol fallback remains in effect. UCC `r_50` is not rendered as an outline diameter.
