Implementiere im bestehenden NightSkyAtlas-Code eine reproduzierbare Sichtbarkeitsklassifikation für visuell beobachtete Galaxien auf Basis von Andrew Crumeys Kontrastschwellenmodell und OpenNGC.

Arbeite selbständig. Lies zuerst vollständig `AGENTS.md`, untersuche danach bestehende Datenmodelle, OpenNGC-Import, Konfiguration, Renderer und Tests. Passe die Implementierung an die vorhandene Architektur an; führe keine unnötige Umstrukturierung durch.

## Ziel

Jede OpenNGC-Galaxie vom Typ `G` soll drei optimierte Sichtbarkeitsscores für 100, 200 und 400 mm Öffnung erhalten. Daraus wird ausschließlich der Konturstil bestimmt:

```text
S100 >= -0.25                          bold
S100 < -0.25 und S200 >= -0.25         normal
S200 < -0.25 und S400 >= -0.25         fine
S400 < -0.25                           dotted
keine ausreichenden Daten              unclassified
```

Semantik:

```text
bold         mit 100 mm erreichbar, daher mit 200 mm relativ einfach
normal       mit 200 mm erreichbar
fine         erst mit 400 mm erreichbar
dotted       auch mit 400 mm extrem / unsicher, aber nicht garantiert unsichtbar
unclassified keine verlässliche Berechnung
```

Die Sichtbarkeitsklasse beeinflusst nur Galaxienkontur bzw. Galaxiensymbol. Die bestehende Beschriftungslogik bleibt unabhängig:

```text
Messier:       fett und etwa 15 % grösser
Herschel 400:  fett
normales NGC:  regular
IC:            regular
```

Eine Galaxie kann daher beispielsweise eine fette H400-Beschriftung, aber eine feine Kontur besitzen.

## Wissenschaftliche Abgrenzung

Crumey liefert die Kontrastschwelle für ein gleichmässiges ausgedehntes Objekt. Folgende Teile sind NightSkyAtlas-Heuristiken und müssen im Code und in der Dokumentation entsprechend bezeichnet werden:

- Zuordnung Hubble-Typ → Sérsic-Index
- Farb-Fallbacks
- Rekonstruktion innerer Teilaperturen
- Referenzbedingungen
- Scoregrenze `-0.25`
- Konturklassifikation
- Confidence-Bewertung

Das Ergebnis bedeutet: Detektion irgendeines integrierten Galaxienlichts. Es sagt nichts Verlässliches über Spiralarme, Staubbänder, H-II-Regionen oder den vollständigen D25-Durchmesser aus.

## Fallback für Flächenhelligkeit

Verwende folgende Reihenfolge:

1. Wenn `SurfBr` vorhanden ist:

```python
mu_b_25 = float(SurfBr)
source = "openngc_surfbr"
```

2. Sonst, wenn `B-Mag` und beide Achsen vorhanden sind:

\[
A_{\rm arcsec^2}=3600\frac{\pi}{4}ab
\]

\[
\bar\mu_B=m_B+2.5\log_{10}(A_{\rm arcsec^2})
\]

```python
source = "derived_from_b_mag"
```

3. Sonst, wenn nur `V-Mag` vorhanden ist:

\[
m_B=m_V+(B-V)_{\rm prior}
\]

Danach dieselbe Flächenformel verwenden:

```python
source = "derived_from_v_mag_and_colour_prior"
```

4. Ohne verwendbare Photometrie:

```python
contour_class = UNCLASSIFIED
score = None
reason = "missing_photometry"
```

Wenn `MajAx` fehlt, ebenfalls `UNCLASSIFIED`.

Wenn nur `MinAx` fehlt, darf `MinAx = MajAx` verwendet werden, aber nur mit niedriger Confidence und dem Grund `missing_minor_axis`.

Verwende volle Katalogachsen, keine Halbachsen.

## Farbe

Wenn B- und V-Magnitude vorhanden sind:

```python
candidate = b_mag - v_mag
```

Akzeptiere den Wert nur, wenn:

```python
0.0 <= candidate <= 1.5
abs(candidate - morphology_colour_prior) <= 0.25
```

Sonst verwende den Morphologie-Prior.

Die effektive visuelle Flächenhelligkeit ist:

\[
\mu_{\rm eff}
=
\mu_B-(B-V)+0.27[(B-V)-0.7]
\]

Implementiere:

```python
def effective_visual_surface_brightness(
    mu_b: float,
    b_minus_v: float,
) -> float:
    return mu_b - b_minus_v + 0.27 * (b_minus_v - 0.7)
```

## Sérsic-Teilaperturen

OpenNGC `SurfBr` wird als mittlere B-Flächenhelligkeit innerhalb der D25-Ellipse interpretiert.

Für \(\bar\mu_{B,25}<25\) löse \(x_{25}\) numerisch aus:

\[
\frac{
  2n\,e^{x_{25}}\gamma(2n,x_{25})
}{
  x_{25}^{2n}
}
=
10^{0.4(25-\bar\mu_{B,25})}
\]

Verwende `scipy.optimize.brentq` und `scipy.special.gammainc`/`gamma`. Falls SciPy noch keine Projektabhängigkeit ist, füge es über den bestehenden Dependency-Mechanismus hinzu. Implementiere die Spezialfunktionen nicht selbst.

Referenzfunktion:

```python
def solve_x25(n: float, mean_mu_b_25: float) -> float | None:
    target = 10.0 ** (0.4 * (25.0 - mean_mu_b_25))
    if target <= 1.0:
        return None

    def residual(x: float) -> float:
        lower_gamma = gammainc(2.0 * n, x) * gamma(2.0 * n)
        ratio = (
            2.0
            * n
            * exp(x)
            * lower_gamma
            / x ** (2.0 * n)
        )
        return ratio - target

    return brentq(residual, 1.0e-4, 100.0)
```

Erzeuge bei gültigem \(x_{25}\):

```python
fractions = numpy.geomspace(0.10, 1.0, 41)
```

Für jede Fraktion:

\[
\bar\mu_B(f)=\bar\mu_{B,25}
-2.5\log_{10}
\left[
\frac{
  \gamma(2n,x_{25}f^{1/n})
}{
  f^2\gamma(2n,x_{25})
}
\right]
\]

Da sich \(\Gamma(2n)\) im Verhältnis kürzt, darf direkt die regularisierte SciPy-Funktion verwendet werden:

```python
def mean_mu_b_within_fraction(
    mean_mu_b_25: float,
    n: float,
    x25: float,
    fraction: float,
) -> float:
    numerator = gammainc(
        2.0 * n,
        x25 * fraction ** (1.0 / n),
    )
    denominator = gammainc(2.0 * n, x25)
    flux_per_area_ratio = (
        numerator / denominator
    ) / fraction**2

    return (
        mean_mu_b_25
        - 2.5 * log10(flux_per_area_ratio)
    )
```

Der Raumwinkel der Teilapertur ist:

\[
A(f)=
\frac{\pi}{4}abf^2
\left(\frac{\pi}{180\cdot60}\right)^2
\]

```python
def ellipse_area_sr(
    major_arcmin: float,
    minor_arcmin: float,
    fraction: float = 1.0,
) -> float:
    area_arcmin2 = (
        pi / 4.0
        * major_arcmin
        * minor_arcmin
        * fraction**2
    )
    return area_arcmin2 * (pi / (180.0 * 60.0)) ** 2
```

Wenn `mu_b_25 >= 25`, die Profilgleichung nicht lösen. Verwende ausschließlich `fraction = 1.0` als gleichmässige Ellipse und reduziere die Confidence.

Falls der Solver unerwartet scheitert, verwende ebenfalls nur die vollständige gleichmässige Ellipse, protokolliere den Grund und lasse den Build nicht abstürzen.

## Crumey-Kontrastmodell

Umrechnung der Himmelhelligkeit:

\[
B_{\rm sky}
=
10^{(12.58-\mu_{\rm sky})/2.5}
\quad {\rm cd/m^2}
\]

```python
def sky_luminance_cd_m2(
    sky_mag_arcsec2: float,
) -> float:
    return 10.0 ** (
        (12.58 - sky_mag_arcsec2) / 2.5
    )
```

Bei 21.5 mag/arcsec² muss ungefähr gelten:

```python
B_sky == approx(2.70e-4, rel=0.01)
```

Für Öffnung \(D\) und Austrittspupille \(d\):

\[
M=\frac{D}{d}
\]

\[
B_a=
B_{\rm sky}\tau
\left(
  \frac{\min(d,p)}{p}
\right)^2
\]

Für das Schwellenmodell:

\[
B_{\rm model}=\max(B_a,10^{-5})
\]

\[
R(B)=
(r_1B^{-1/4}+r_2)^2
\]

\[
C_\infty(B)=
k_1B^{-1/4}+k_2
\]

\[
A_a=M^2A
\]

\[
C_{\rm req}
=
\phi
\left[
\left(
  \frac{R(B_{\rm model})}{A_a}
\right)^q
+
C_\infty(B_{\rm model})^q
\right]^{1/q}
\]

Referenzfunktion:

```python
def crumey_required_contrast(
    area_sr: float,
    aperture_mm: float,
    exit_pupil_mm: float,
    conditions: VisibilityConditions,
) -> float:
    magnification = aperture_mm / exit_pupil_mm

    sky = sky_luminance_cd_m2(
        conditions.sky_mag_arcsec2
    )

    apparent_sky = (
        sky
        * conditions.transmission
        * (
            min(
                exit_pupil_mm,
                conditions.eye_pupil_mm,
            )
            / conditions.eye_pupil_mm
        )
        ** 2
    )

    background = max(
        apparent_sky,
        ZERO_BACKGROUND_CD_M2,
    )

    r = (
        R1 * background ** (-0.25) + R2
    ) ** 2

    c_infinity = (
        K1 * background ** (-0.25) + K2
    )

    apparent_area = (
        magnification**2 * area_sr
    )

    raw_threshold = (
        (r / apparent_area) ** Q
        + c_infinity**Q
    ) ** (1.0 / Q)

    return (
        conditions.field_factor * raw_threshold
    )
```

Der Objektkontrast ist:

\[
C_{\rm obj}
=
10^{-0.4(\mu_{\rm eff}-\mu_{\rm sky})}
\]

Wichtig:

- Nicht `-1` rechnen.
- Transmission nicht nochmals auf `C_obj` anwenden.
- Teleskoptransmission verändert die Adaptationshelligkeit, nicht den Objekt/Himmel-Kontrast.
- Keine Stern-Grenzgrössenformel verwenden.

Der Score lautet:

\[
S=
2.5\log_{10}
\left(
\frac{C_{\rm obj}}{C_{\rm req}}
\right)
\]

```python
def visibility_score(
    object_contrast: float,
    required_contrast: float,
) -> float:
    return 2.5 * log10(
        object_contrast / required_contrast
    )
```

Interpretation:

```text
S = 0       angenommene konservative Detektionsschwelle
S = 0.75    Objektkontrast etwa doppelt so gross wie die Schwelle
S < 0       unterhalb der konservativen Schwelle
S >= -0.25  für die grobe Atlas-Klassifikation noch erreichbar
```

## Confidence

Beginne bei 3 Punkten. Ziehe jeweils höchstens einen Punkt ab für:

```text
Farbwert musste aus Morphologie abgeleitet werden
Morphologie fehlt oder enthält Unsicherheit
SurfBr fehlt und wurde aus Magnitude berechnet
SurfBr und B-Mag/Ellipsenwert unterscheiden sich um mehr als 0.75 mag
optimale Profilfraktion < 0.20
mu_b_25 >= 24.9 oder Profilsolver-Fallback
Minor-Achse fehlt oder Datenquelle erscheint ungeeignet
```

Begrenze den Wert auf mindestens 0:

```text
3      high
2      medium
0–1    low
```

Confidence verändert niemals den Score oder Konturstil. Sie dient nur Diagnose und späterer Qualitätskontrolle.

## Performance

Eine vollständige OpenNGC-Auswertung soll nicht pro Diagrammelement in verschachtelten Python-Schleifen erfolgen.

Bevorzugt:

- NumPy-Broadcasting über Profilfraktionen und Austrittspupillen;
- einmalige Berechnung beim Katalogimport;
- Cache je Galaxie und Referenzkonfiguration.

Ein kompletter Lauf über etwa 10 500 Galaxien sollte im Sekunden- bis niedrigen zweistelligen Sekundenbereich bleiben.

## Dokumentation

Ergänze eine kurze Dokumentation mit diesem Inhalt:

> NightSkyAtlas schätzt die visuelle Erkennbarkeit von Galaxien mit einem approximativen Kontrastschwellenmodell nach Andrew Crumey.
